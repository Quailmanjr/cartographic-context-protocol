# Cartographic Context Protocol

Cartographic Context Protocol is a small repository-navigation convention for AI agents and humans working in a codebase.

It is meant to keep project context explicit in files so a new session can orient before editing. It is not a security boundary, a memory system, or proof of any performance gain.

## Core Idea

- `WORLD_MAP.md` describes the major areas of a repository.
- `LEGEND.md` describes a directory's files and local rules.
- `JOURNEY.md` or session notes capture active handoff state when useful.

Use it when a repository is large enough that repeated orientation work is slowing down edits. Keep the files short, current, and factual.
